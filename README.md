## ✏️ 한줄 소개
오늘 하루를 위한 위젯 페이지

## 🗓️ 진행 기간
2022.02.03

## 👤 팀 구성
개인 프로젝트

## 📜 서비스 내용
- 오늘 할 일과 일정에 대해 제공해주는 서비스입니다.
- 현재 위 서비스에서 제공하는 핵심 기능 3가지입니다.
- `로컬 스토리지`를 이용한 to-do 리스트
- `API`를 이용한 현재에 대한 정보 (시간, 위치기반 날씨)
- 동기부여를 위한 명언 랜덤 표기

## 🛠 기술 스택
- HTML/CSS
- vanilla JS

## 🖥 개발 내용
1. 새로고침을 할 때마다 랜덤으로 배경이 바뀐다.
2. 할 일 기능 할일을 추가, 삭제, 완료를 할 수 있다.
3. 새로고침을 할 때마다 랜덤으로 명언이 바뀐다.
4. 시간이 실시간으로 흐르고 1초마다 am/pm 부분이 깜빡인다.
5. 실시간으로 기상상태를 받아와서 표시해준다.
6. 오늘의 날짜를 표시하고, 오늘의 일정을 작성할 수 있다.

- 로컬스토리지와 외부 api를 사용하는 법을 알게되고 데이터를 사용할 수 있게 되었습니다.
